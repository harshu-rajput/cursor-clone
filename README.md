# Cursor Clone

A pixel-accurate clone of the Cursor AI website homepage built using pure HTML and CSS.

---

## About the Project

This project is a front-end clone of the official Cursor website UI.  
It is built to practice and demonstrate strong skills in **HTML structure**, **CSS layout**, and **modern UI styling** without using any JavaScript frameworks or libraries.

The focus of this project is:
- Clean and readable HTML structure
- Well-organized and maintainable CSS
- Accurate spacing, typography, and layout replication
- Professional sectioning similar to a real-world SaaS website

This project is purely for **educational and practice purposes**.

---

## Tech Stack

- HTML5  
- CSS3  

No JavaScript, frameworks, or UI libraries are used.

---

## Features Implemented

- Sticky navigation bar
- Hero section with CTA
- Brand logos section
- Feature showcase sections
- Testimonials grid
- Frontier / product highlight cards
- Changelog section
- Team / Join banner
- Recent highlights section
- Call-to-action section
- Complete footer layout
